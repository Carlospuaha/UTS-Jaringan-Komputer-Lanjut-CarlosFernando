## Carlos Fernando (20220801035)

Simulasi jaringan menggunakan Cisco Packet Tracer dengan konfigurasi VLAN dan Inter-VLAN Routing (Router-on-a-Stick).

### File dalam Repository
- `UTS Jaringan Komputer Lanjut_Carlos Fernando_20220801035.pdf` → Laporan UTS

### 📖 Deskripsi
Topologi terdiri dari 5 VLAN:
| VLAN | Nama | IP Gateway | Perangkat |
|------|------|-------------|------------|
| 10 | Yayasan | 192.168.10.1 | PC0 |
| 20 | Guru | 192.168.20.1 | PC1 |
| 30 | CCTV | 192.168.30.1 | CCTV |
| 40 | NVR | 192.168.40.1 | Server |
| 50 | Hotspot | 192.168.50.1 | Access Point |

Semua VLAN berhasil saling berkomunikasi menggunakan konfigurasi **Router-on-a-Stick**.
